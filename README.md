# KidCoin 🪙

Plataforma gamificada de educação financeira infantil para escolas: aulas em módulos, programação em blocos, mobile e IoT.

> Projeto Interdisciplinar, FATEC Votorantim, 2026/2. Banca: 30/11/2026.

## Sobre o projeto

O KidCoin ajuda professores a ensinar educação financeira para crianças do ensino fundamental (1º ao 3º ano) por meio de aulas prontas em módulos. As crianças aprendem conceitos de dinheiro programando em blocos e vendo o resultado funcionar em um dispositivo físico, como um cofrinho que contabiliza moedas.

O professor é o usuário central: a plataforma entrega a aula pronta, acompanha o progresso da turma e mostra os resultados para a gestão da escola.

## Origem do projeto

Este projeto é a evolução do [KidCoin-Project](https://github.com/camycamyha/KidCoin-Project), desenvolvido desde o 1º semestre. Nesta versão, o site foi repensado do zero, a partir da vivência em sala de aula, e o projeto passa a incluir programação em blocos, aplicativo mobile e IoT.

## Frentes do semestre

- **Web:** site para professores e alunos, com aulas em módulos e editor de programação em blocos.
- **Mobile:** aplicativo em React Native.
- **IoT:** dispositivo físico (cofrinho) programado pelas crianças por meio dos blocos.
- **Primeiro módulo:** a história do escambo.
